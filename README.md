# Dental Caries ROI Segmentation Framework

This repository provides the implementation of a deep learning framework for dental caries ROI segmentation in intraoral periapical radiographs, including preprocessing, ROI cropping, baseline and proposed segmentation models, and comprehensive evaluation.

The implementation includes ROI generation and preprocessing, multiple baseline models and the proposed context-aware FiLM-modulated U-Net, multi-seed experiments for reproducibility, and ablation studies to evaluate the contribution of individual components.

Statistical analysis is provided to compare model performance, including appropriate significance testing and post-hoc analysis. In addition, bootstrap-based 95% confidence intervals are computed for the test-set performance metrics to quantify the statistical uncertainty and robustness of the reported results.
